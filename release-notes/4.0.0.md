antcat.org now runs on current, supported software. Editors should see no difference in the catalog; please report anything that looks wrong through the Feedback link.

### What changed since 3.7.18.5 (December 2024)
- Ruby 4.0.7, Rails 8.1, MySQL 8.4 LTS, Solr 10, Node 26.
- Page styles and scripts rebuilt with current tools (esbuild, dart-sass, Tailwind 4, Turbo 8).
- Reference PDFs served directly from the same storage, without the unmaintained paperclip library.
- Library updates, including security fixes in the login library.
- Forms check the shape of submitted data and give a clear error for a malformed request.
- In the taxon browser, misspellings are shown in brown and homonyms in magenta (explained in the legend).
- The nightly export to AntWeb uses the terminal valid name as "current valid name" (for example *Lasius (Dendrolasius)* now exports *Lasius*).
- Tests run automatically on GitHub again, and changes are tried on a staging server before going live.
